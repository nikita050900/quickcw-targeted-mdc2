# Enterprise runs (H to K)

Runs H to K of Table 3 use Enterprise and PTMCMCSampler rather than QuickCW,
and provide the independent cross check of Sections 5.1 and 5.3. Those
analyses were carried out by B. Larsen.

The scripts are available at:

    [placeholder, to be filled in by B. Larsen]

The configuration is given in Section 3 and Table 2 of the paper. The pulsar
objects and noise files are the same ones built by `dataset/`, and the common
process is modelled as uncorrelated common red noise so that all three
pipelines share a GWB model.

Software used:

- Enterprise, https://github.com/nanograv/enterprise
- enterprise_extensions, https://github.com/nanograv/enterprise_extensions
- PTMCMCSampler, https://github.com/jellis18/PTMCMCSampler
